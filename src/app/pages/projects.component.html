01

Dieses Portfolio

TypeScript / Angular / Tailwind CSS

Eine eigenständig konzipierte und entwickelte Portfolio-Website, umgesetzt mit Angular und TypeScript sowie gestaltet mit Tailwind CSS. Das responsive Editorial-Design unterstützt Light- und Dark-Mode und legt besonderen Wert auf Zugänglichkeit sowie eine konsistente Darstellung auf allen Bildschirmgrößen.

Herausforderung

Bestehende Vorlagen wirkten generisch. Ziel war eine eigenständige, editorial wirkende Seite mit klarer Typografie und einem echten Light-/Dark-Modus statt reiner Farbinvertierung.

Ansatz

Aufbau mit Angular (Standalone Components, Signals) und Tailwind CSS. Theming läuft über CSS-Variablen wie --bg, --fg und --accent, sodass jede Komponente automatisch auf den Modus reagiert.

Ergebnis

Eine vollständig responsive Seite mit Lightbox, Kontaktformular und Case Studies wie dieser — berufsbegleitend als eigenständiges Projekt umgesetzt.

02

Lumi Dashboard

HTML / SCSS / TypeScript / Angular

Ein Web-Dashboard für den Discord-Bot „Lumi”, das ich gemeinsam mit Norman Höhn entwickle, damit Serverbetreiber ihre Community direkt im Browser verwalten können. Mitglieder lassen sich moderieren, individuelle Embeds und Panels gestalten sowie Berechtigungen feingranular vergeben — einzelne Module wie Tickets, Tutorials oder Geburtstage sind unabhängig voneinander aktivierbar.

Website kontakt@luminanetwork.de
@if (isExpanded('lumi')) {
Herausforderung

Serverbetreiber sollten komplexe Embeds und Panels bauen und Rechte feingranular vergeben können — ohne Discord-Entwicklerkenntnisse und ohne vom Funktionsumfang erschlagen zu werden.

Ansatz

Ein modulares Berechtigungssystem macht einzelne Features wie Tickets, Tutorials oder Geburtstage unabhängig voneinander aktivierbar, ergänzt durch einen visuellen Embed-Editor mit Live-Vorschau — gemeinsam mit Norman Höhn entwickelt.

Ergebnis

Serverbetreiber der Lumina Network Community verwalten ihre komplette Konfiguration direkt im Browser statt über Slash-Commands im Discord-Client.

03

BolusManager

Kotlin / Jetpack Compose / Room

Eine native Android-App zur Planung von Insulin-Bolusdosen, entwickelt mit Kotlin und Jetpack Compose (Material 3) sowie lokaler Datenhaltung über Room. Sie verwaltet persönliche Korrekturfaktoren und Tageszeitpläne, berechnet normale und aufgeteilte Boli in Echtzeit und speichert häufig genutzte Kohlenhydratmengen als Schnellzugriff.

GitHub
@if (isExpanded('bolus')) {
Herausforderung

Bestehende Insulin-Rechner waren entweder zu simpel — keine aufgeteilten Boli — oder zu unübersichtlich für den schnellen Alltagseinsatz.

Ansatz

Native Android-App mit Kotlin und Jetpack Compose (Material 3), lokale Datenhaltung über Room für volle Offline-Fähigkeit. Die Berechnung basiert auf individuellen Korrekturfaktoren und Tageszeitplänen.

Ergebnis

Die Zeit für eine Bolus-Berechnung im Alltag reduziert sich auf wenige Sekunden. Die Demo unten zeigt vereinfacht, wie die App aus Kohlenhydraten und Blutzuckerwert eine Dosis ableitet.
